Ping Death is a fast-paced 2D action-puzzle game. The player controls a main character whose goal is to reconnect a failing server network by directly clicking with the mouse on illuminated Routers to move the character toward them and activate them in sequence, while avoiding the bugs that block the path.

Controls: Left Mouse Click on the illuminated Router to move the character, activate the node, and avoid bugs along the way.
